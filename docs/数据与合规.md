# Kickoff · 启学引擎 — 数据来源与合规说明

> 依据《GOAI 无界应用|Boundless Agents 参赛手册》§6.2/§8.4/§9 编写 · 2026-08-17
> 本文档适用于 Kickoff Web 应用(PWA)、桌面伴侣(Electron)与微信小程序骨架三端 —— 三端共用同一后端与同一数据体系。

---

## 1. 数据类型清单

| 类别 | 具体数据 | 产生方式 | 示例 |
|---|---|---|---|
| 用户输入 | 学习目标、动机、学习资源(用户自行粘贴的链接/书名/要点)、情绪选择(还行/焦虑/累/不知道从哪开始)、打卡记录、杂念停车场文本、对话消息 | 用户主动输入 | "自学吉他弹唱"+一条 B 站链接 |
| 系统生成 | 周计划与任务、拆解步骤与启动卡、复盘报告、学情画像与拖延画像 | LLM/规则引擎基于用户输入生成 | 粒度矩阵、卡点分布 |
| 技术日志 | 服务端运行日志(仅开发调试用,不含分析追踪) | 自动 | — |

**不收集**:姓名、手机号、身份证件、位置、通讯录、相册、设备指纹;**无**第三方统计/广告/追踪 SDK;**无** Cookie 分析。

## 2. 数据来源与授权状态

| 数据 | 来源 | 授权状态 |
|---|---|---|
| 演示/评测数据 | `data/simulated/generate.ts` 脚本生成(固定 seed=42,3 个虚构画像 × 30 天) | 完全合成,不对应任何真实个人;`eval/report.md` 已明确标注"模拟数据,非真实用户" |
| 学习路线知识库(Python 数据分析/英语四级) | freeCodeCamp、CS50、The Odin Project 等公开课程大纲的**结构化重构**(非原文复制),用于生成任务标题 | 公开资料重构,任务文案为原创改写 |
| 循证策略库 | 公开学术文献结论的引用与标注(Steel 2007、Sirois & Pychyl 2013、Gollwitzer & Sheeran 2006 等),每条标注证据强度 | 学术引用,来源见项目计划书 §8.1 |
| 用户自定义技能包 | 用户自行粘贴的资源与生成的路线 | 归用户所有,见 §4 |
| 模型输出 | 商业 LLM API(OpenAI 兼容接口) | 见 §6 第三方披露 |

## 3. 隐私保护措施

1. **最小化收集**:仅采集产品运行必需字段(见 §1),情绪仅四选项固定枚举,不采集自由文本健康信息;
2. **存储位置**:SQLite 数据库随部署实例存储(部署方持有);当前单演示用户模式,无跨用户数据访问面;
3. **敏感数据隔离**:专注支持模式偏好按健康相关数据处理 —— 仅存储开关与时长参数,**不存储**任何诊断/测评类内容(产品明确不做 ADHD 筛查或评分);
4. **传输**:上线部署强制 HTTPS(Vercel/Docker 均默认支持);
5. **数据主体权利(已实现的产品功能)**:
   - **查看**:「画像」页完整展示双画像全部字段,用户可核对与纠错;
   - **导出**:「画像」页「导出我的数据」按钮 → `GET /api/export` 返回全量 JSON;
   - **删除**:「一键删除」按钮 → `DELETE /api/profile` 清除全部目标/计划/打卡/画像/停车场数据并重建空账户(接口已验证)。

## 4. 行业边界与风险提示

依据手册 §9.3 及 FAQ Q12:

1. **不替代教育评价**:输出为学习建议与行为干预,不构成学业评定,不提供应试评分;作业类请求触发引导模式(分步提示/错因分析),**不直接生成标准答案**;
2. **非医疗边界**:产品定位为学习与自我管理工具,**不诊断、不治疗、不替代**专业医疗或心理服务;
   - 免责声明常驻:「Kickoff 是学习与自我管理工具,不构成医疗建议或诊断,不替代专业治疗」;
   - **危机转介已内建**:对话中检测到自伤等危机关键词时,系统跳过全部正常流程,展示心理援助热线(12356 等,`src/lib/crisis.ts`,已实测验证);
3. **无羞耻原则**:不以焦虑/内疚作为留存手段,断签后为"原谅+重新开始"而非惩罚性警示;
4. **用户年龄**:目标用户定位为成人自学者(18+);当前不面向未成年人提供服务,后续如扩展需监护人同意与额外合规评估;
5. ** AI 生成内容不确定性**:计划/拆解/复盘由模型生成,产品通过结构化校验(zod)约束输出,并在信息不足时追问而非编造;用户可随时"换更小的步骤"或重新生成。

## 5. 第三方依赖披露

| 依赖 | 用途 | 许可/费用 |
|---|---|---|
| 商业 LLM API(可切换 DeepSeek/Qwen/GLM 等,OpenAI 兼容) | 计划生成/拆解/复盘润色/意图路由 | 按量付费;未配置 Key 时系统运行于内置确定性 Mock 模式(无外发数据);**替换仅需改环境变量,无锁定** |
| Next.js / React / Prisma / zod / Electron | 框架 | MIT 等 OSI 许可 |
| 公开课程大纲 | 知识库重构来源 | 公开资料,已改写 |

## 6. 部署形态说明

- 本地/自托管(Docker Compose,数据卷持久化)或 Vercel(无持久磁盘,SQLite 为实例级);
- 三端(网页/桌面/小程序)共用同一 API,均通过显式配置的服务器地址访问,**不引入额外数据副本**;
- 日志仅用于故障排查,不用于用户画像或模型训练。
